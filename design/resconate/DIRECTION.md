# Resconate — storefront assistant

## Brief
User-provided: redesign the website and working application around the business plan. Nigerian small employers, initial food-business segment. Core action: record work, an advance, or a payment and review what is owed. Existing logo retained. Responsive web build; native iOS chrome is not applicable. Feel and references are self-authored: dependable, familiar, direct; shop awnings, a working counter, handwritten staff notebooks. Original SVG illustrations; no paid image generation.

## Current app
Dark navy, violet/pink gradients, blurred lighting, oversized cards, uppercase metadata and disconnected user flows. Keep: brand/logo, employee records, payroll, banking, leave, recruitment, performance, exports, support and subscription intent. Reframe advanced functions as optional workforce tools; preserve old URLs through redirects. Lose: invented testimonials, metrics, compliance guarantees, simulated money, decorative glow and old pricing. Legacy source remains available but is excluded from the new production routes. Unknown: provider account approvals and live credentials.

No Apple fonts required for web.

## Richness
Custom cut-shape shop illustration, navy outlines, warm paper, muted blue surfaces, one consistent hand. Secondary drawings: worker register, statement, conversation. Logo silhouette reproduced from provided PNG by transparent crop, not redrawn.

## Signature
Record -> review -> receipt: opening a record sheet expands from the relevant action. Confirming creates an explicit receipt and updates the balance; receipt slides 8px into place over 180ms. Reduced motion uses immediate state change. Optional vibration only after success, unsupported devices remain functional.
